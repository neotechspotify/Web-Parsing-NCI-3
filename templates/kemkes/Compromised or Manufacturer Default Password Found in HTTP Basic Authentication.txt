Firewall Palo Alto mendeteksi lalu lintas yang sesuai dengan signature Compromised or Manufacturer Default Password Found in HTTP Basic Authentication. Alert ini mengindikasikan bahwa permintaan HTTP Basic Authentication mengandung kredensial yang cocok dengan daftar password default perangkat atau password yang telah diketahui bocor. Aktivitas tersebut dapat merupakan upaya untuk memperoleh akses tidak sah menggunakan kredensial yang lemah atau telah terekspos. Berdasarkan log yang diterima, firewall menghasilkan aksi Alert dengan tingkat keparahan Informational, sehingga diperlukan verifikasi lebih lanjut untuk memastikan apakah proses autentikasi berhasil dan apakah kredensial yang digunakan merupakan akun yang valid.


===============================

Mitigasi :<br>
- Verifikasi pada web server atau aplikasi tujuan apakah terdapat percobaan autentikasi menggunakan HTTP Basic Authentication pada waktu kejadian.
- Periksa log autentikasi untuk memastikan apakah proses login berhasil atau ditolak.
- Pastikan seluruh akun tidak lagi menggunakan password bawaan (default) atau password yang telah diketahui bocor.
- Terapkan kebijakan password yang kuat dan unik, serta lakukan penggantian password apabila ditemukan penggunaan kredensial yang lemah.
- Apabila memungkinkan, nonaktifkan HTTP Basic Authentication atau gunakan metode autentikasi yang lebih aman, seperti autentikasi berbasis token atau Multi-Factor Authentication (MFA).
- Lakukan monitoring terhadap aktivitas lanjutan dari alamat IP sumber dan pertimbangkan pemblokiran apabila teridentifikasi sebagai upaya brute force atau percobaan akses yang tidak sah secara berulang.
