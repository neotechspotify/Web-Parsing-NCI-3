===============================

Terdeteksi adanya permintaan HTTP menuju endpoint /solr/admin/info/system pada server  yang merupakan endpoint administrasi Apache Solr. Request ini mengindikasikan aktivitas reconnaissance (pemindaian) untuk mengidentifikasi keberadaan dan memperoleh informasi sistem Apache Solr.

===============================

Mitigasi :

- Verifikasi apakah server memang menjalankan layanan Apache Solr.
- Pastikan endpoint administrasi Apache Solr (/solr/admin/*) tidak dapat diakses dari jaringan publik apabila tidak diperlukan.
- Aktifkan autentikasi dan otorisasi pada Apache Solr Admin API.
- Perbarui Apache Solr ke versi terbaru yang telah mendapatkan patch keamanan.
